# Part 33 — Multitool Gateway Policy Enforcement

**AgentCore capability:** Policy

Same Cedar policy pattern as Part 32, applied to the multi-tool Gateway from Parts 19–20 — shows that policy enforcement is scoped per action, so other tools on the same Gateway remain unaffected.

## Prerequisites

- The Part 19/20 multi-tool Gateway with a policy engine attached

## Run it

1. Review `Cedar Policy NLP.txt`
2. `bash 'Policy Gateway Asso.sh'`
3. Confirm the restricted action is denied while other tools on the Gateway still work
