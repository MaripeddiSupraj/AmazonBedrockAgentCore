# Part 46 — Create Your First Registry & Publish an MCP Server Record

**AgentCore capability:** Registry

Introduces the AgentCore Registry: publishes a mock MCP server description (`mcp-server/MyMCPServer.json`) as a discoverable record, using the AWS CLI commands in `commands/`.

## Prerequisites

- AgentCore Registry enabled for your account

## Run it

1. Review `mcp-server/MyMCPServer.json`
2. Run the commands in `commands/AWS Agent Registry Commands.txt` to publish the record
