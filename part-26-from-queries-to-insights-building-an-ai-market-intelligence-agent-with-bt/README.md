# Part 26 — From Queries to Insights: Building an AI Market Intelligence Agent with the Browser Tool

**AgentCore capability:** Browser

First lab to use the AgentCore managed Browser tool (`aws.browser.v1`): the agent researches competitors live on the web and summarizes findings for a business audience, instead of relying on the model's own training data.

## Prerequisites

- Browser tool enabled for your AgentCore account/region

## Run it

1. `bash setup/Pythonsetup.sh && bash setup/Envsetup.sh`
2. `bash agent/deploy.sh`, deploy as a Runtime agent
3. Ask it to research a specific competitor or market
