# Part 41 — Payment Infrastructure Setup

**AgentCore capability:** Payments

Reference notes (no code) for standing up AgentCore Payments: checking a wallet's balance and creating a payment instrument, both against the x402 micropayment protocol that Payments is built on.

## Prerequisites

- AgentCore Payments enabled for your account

## Run it

1. Follow `CheckWalletBalance.txt` to confirm your wallet is funded
2. Follow `CreatePaymentInstrument.txt` to create the instrument used in Part 42
